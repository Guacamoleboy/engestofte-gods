# PDF-materialer

Denne mappe indeholder de originale PDF-filer fra kundematerialet. De er bevaret urørte og fungerer som reference til blandt andet grundpakker, ansøgningsskema og stadeplaner.

PDF'erne bør først udtrækkes eller omskrives til strukturerede data, når den konkrete prototype kræver det.

Der ligger søgbare tekstudtræk og en ekstra PDF-backup i [kilder](../kilder/): [pdf-tekst](../kilder/pdf-tekst/) og [pdf-backup](../kilder/pdf-backup/).
